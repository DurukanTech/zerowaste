# ♻️ Sıfır Atık Savaşçısı (Zero Waste Warrior)

> 3D, Vampire Survivors tarzı roguelite. Antalya sahilindeki bir parkı istila eden **atık canavarlarına** karşı 10 dakika hayatta kal, malzemeleri topla, **doğru renkteki geri dönüşüm kutusuna** götür, **Aşırı Tüketim Devi**'ni yen.

## Hızlı Bilgiler
| | |
|---|---|
| Tema | **Sıfır Atık** (COP31 Türkiye başlıklarından) |
| Motor | Godot 4.7.2, GDScript, *GL Compatibility* renderer |
| Ekip / Süre | 1 kişi / 48 saat |
| Platform | PC (Windows) + Web (itch.io) |
| Dil | Türkçe + İngilizce |
| Run süresi | 10 dakika, final boss ile biter |
| Görsel | Godot primitive mesh'leri ile low-poly, harici asset yok |
| Proje klasörü | `../game/` |
